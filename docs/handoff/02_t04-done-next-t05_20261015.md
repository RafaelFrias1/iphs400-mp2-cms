## Gotchas
- **`.env` is not loaded automatically.** Start the console with `set -a; . ./.env; set +a; uv run cms serve`. Without that, it runs on the default secret key.
- **Quote values with spaces or apostrophes in `.env`**, for example `CMS_SITE_TITLE="Kenyon Men's Golf CMS"`. The file is sourced as shell.
- **markdown-it leaves `[x](javascript:…)` as plain text.** Test for `href="javascript:`, not for the bare word.
- **"live" and "posted" are banned words in `CONTEXT.md`.** Use "published", including in test strings.
- **Never print passwords in chat.** Transcripts are committed to `docs/transcripts/`.
