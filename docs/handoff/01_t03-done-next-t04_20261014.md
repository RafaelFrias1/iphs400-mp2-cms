## Decisions and why
- **Posts and pages share one `items` table** with a `kind` column, because spec #1 says "one content item shape". "Item" was added to `CONTEXT.md`.
- **The slug stays fixed** when the title changes, so URLs don't break. Only admins see or set a slug, and only on the edit screen. An editor's `slug` field is ignored.
- **Preview is server-side.** It is a Preview button that saves nothing; there is no JS (ADR-002).
- **Rubric conventions win over CLAUDE.md's** for graded artifacts. Handoffs go in `docs/handoff/{NN}_{purpose}_{YYYYMMDD}.md` (rubric §1, B6b). CLAUDE.md's `docs/handoffs/` standard is not what the checker looks for.
